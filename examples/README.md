# Examples

> 🚧 即将到来 —— 框架第一个可用版本（v0.1）发布后，会在这里放置完整可运行示例。

预期会覆盖的场景：

- **文本分类** —— 情感分析、意图识别
- **信息提取** —— 从非结构化文本抽取结构化字段
- **摘要** —— 长文 → 一句话
- **评分** —— 内容质量、可读性
- **改写 / 翻译** —— 风格转换
- **路由决策** —— 用 LLM 替代规则引擎做条件分支
- **嵌套组合** —— 一个 Agentic Function 调用另一个

每个示例都会是单一文件、可直接 `python examples/xxx.py` 运行。
